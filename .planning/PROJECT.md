# RoynixBotWorks — Premium Discord Bot Marketplace

## Project Overview
RoynixBotWorks is a high-end digital storefront specializing in premium Discord bot source codes, enterprise moderation systems, automation tools, and Discord server management solutions.

## Brand Positioning
- **Name:** RoynixBotWorks
- **Industry:** Discord Bot Development / Digital Software Products
- **Tagline:** "Powerful Bots. Smarter Communities."
- **Aesthetic:** Developer-focused editorial layout, dark charcoal/near-black backgrounds (`#0a0d12`, `#0f141c`, `#151b26`), crisp typography, restrained electric lime/green accents (`#84cc16`, `#22c55e`, `#10b981`), refined borders, authentic Discord interface mockups, zero AI fluff.

## Primary Product Offering
- **Titan Moderation Bot:** Premium Discord Moderation & AutoMod System
  - Category: Discord Moderation
  - Badge: "Premium Source Code"
  - Stack: Node.js 20+, TypeScript, Discord.js v14, Prisma ORM, SQLite/PostgreSQL
  - Features: Advanced moderation commands, automated moderation, anti-spam, server protection, role management, logging, configurable settings, developer-friendly source code.

## Purchasing Architecture
- **Official Checkout / Storefront:** [Whop Storefront](https://whop.com/discord-bot-source-codes/roynixbotworks/)
- **Purchasing Rule:** All purchase/CTA buttons ("Buy Now", "Purchase", "Get Titan", "Get Access", "Unlock Product") must directly redirect the customer to `https://whop.com/discord-bot-source-codes/roynixbotworks/` in the same tab. No fake checkout, no simulated payments, no third-party payment gateways.

## Tech Stack
- React 18 / Vite / TypeScript
- Tailwind CSS with custom design tokens matching RoynixBotWorks branding
- Framer Motion for micro-interactions and transitions
- Lucide React for consistent icons
- Modular architecture with central product catalog data structure
