## ⚡ Overview

**RoynixBotWorks** delivers developer-engineered, uncompiled source code packages for community leaders and server owners who demand total ownership, zero-latency execution, and rock-solid reliability.

- **Featured Product:** Titan Moderation Bot v14
- **Official Storefront & Digital Fulfillment:** [Whop Storefront](https://whop.com/discord-bot-source-codes/roynixbotworks/)
- **Tech Stack:** Node.js 20+ LTS, TypeScript 5.5, Discord.js v14, Prisma ORM (SQLite/PostgreSQL), Docker, PM2
- **Website Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Framer Motion

## 🚀 Features

- **Titan Moderation Bot:** High-performance automated moderation engine with slash command routing, keyword heuristics, anti-invite filters, and embed logging.
- **Interactive Command Simulator:** Explore and preview Discord bot commands and real-time response embeds.
- **Enterprise Self-Hosting:** Pre-configured Docker Compose pipelines and PM2 cluster process supervision.
- **Modular TypeScript Architecture:** Clean separation of command handlers, gateway event listeners, and database models.
- **Direct Whop Integration:** Frictionless digital fulfillment and instant repository access through Whop.

## 🛠️ Local Development & Website Build

### Prerequisites
- Node.js 20.x or higher
- npm 10.x or higher

### Installation
```bash
# Clone the repository
git clone https://github.com/shivaxroy0010/roynixbotworks.git
cd roynixbotworks

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```

---

## 📦 Deployment

The web storefront is configured for instant deployment on Netlify or Vercel:
- **Build Command:** `npm run build`
- **Publish Directory:** `dist`
